Day 6 COVID-19 Trend Analysis

Project Overview
Analyzed COVID-19 trends across 3 states (Maharashtra, Delhi, Karnataka) using Excel. Tracked daily cases, recovery rates, death rates, and positivity rates.

Key Features
- Daily new cases trend analysis
- State-wise cases comparison
- Recovery rate by state
- Death rate by state
- Weekly cases trend
- Positivity rate by state
- KPI cards for key metrics
- Conditional formatting for data visualization
